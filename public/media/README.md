# Media assets required

Place the following real production assets in this folder before deploying.
These binary assets are not generated by the scaffold — the site falls back
gracefully to CSS gradients when they are missing, but real assets are
required for the final look.

- chiptek-hero.mp4         — 8-15s seamless loop, muted, web-optimized, no audio, dark enough for white text overlay
- chiptek-hero-poster.webp — poster frame matching the video's first frame
- chiptek-team.webp        — supporting image for the About section (optional)
- software-engineering.webp
- data-engineering.webp
- ai-engineering.webp      — supporting imagery for service detail pages (optional)

Also place `og-image.webp` (1200x630 social share image) directly in `/public`, not in this folder.
